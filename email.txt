# OMG Rental — Automated Email, Receipt & Reminder System

I want to add a complete automated customer communication system to the OMG Rental application.

The objective is that once a customer's email is available, the system should automatically send the appropriate email based on the customer's booking, payment, pickup, return and settlement status.

The system should use professional, attractive HTML email templates with the **OMG Rental logo, business information and contact number: 7610544284**.

The customer should receive useful communication without staff having to manually write every email.

---

## 1. Email Account & Security

The application should support sending emails through our business email account.

IMPORTANT:


* Only Admin should be able to configure email settings.
* The system should record whether an email was successfully sent, failed or is pending.

Admin settings should include:

* Sender name
* Sender email
* SMTP/API provider
* SMTP host
* Port
* Secure connection
* Username
* Secret/app password
* Reply-to email
* Test email function
